# 旅路三幕 / The Journey in Three Acts — 主题设计

葬送的芙莉莲动画截帧风独立主题。情绪：孤独、忧郁、温暖。

## 定位与既定事实

- 与「深渊下潜」并存的独立第二主题，入口 `journey.html` + `src/journey/`，互设不显眼链接；只共享 `src/config.ts` 与 `src/content/memories.ts`，不 import 深海站任何模块。
- **画面基准 = 三张已认可样张**（2026-07-14 用户选定，动画截帧赛璐璐质感）：
  1. 午后逆光赶路（石板路、蒲公英飞絮、长影）
  2. 黄昏回望（金橙日落草原、黑斗篷背影）
  3. 夜篝火流星（冷蓝星夜 + 暖橙篝火，抱膝望流星）
- 三张角色服装不一致——**接受**，叙事解释为人生不同阶段的装束。v1 不重生成、不改图；统一角色留作后续可选项。
- 画面永远是完整动画帧：**禁止分层拼贴、禁止角色贴图动画**（上一主题被否的两个根因）。

## 结构（滚动 = 三幕人生）

| 幕 | 画面 | 时段 | 内容 |
|---|---|---|---|
| 一 · 午后 | 逆光赶路 | 出生 → 人生前 2/3 | 序章（名字 + 一句话 + 下行提示）+ 早年记忆光点 |
| 二 · 黄昏 | 回望地平线 | 近年 | 近年记忆光点 |
| 三 · 夜 | 篝火流星 | 当下 | 此刻文案 + 社交链接 + 结语留白 |

- 总滚动高度约 9 屏（每幕 3 屏）；幕间各有约 1 屏的**交叉渐变带**（前帧淡出、后帧淡入，无硬切）。
- 幕内推镜（Ken Burns）：当前帧随幕内进度缓慢 scale 1.02 → 1.07 并向画面焦点（人物）轻移，速度以不可察觉为准。
- 记忆按年份升序分配：年份 ≤ 出生年+22 归第一幕，其余归第二幕（阈值实现时按 memories 分布微调，保证两幕数量均衡且各 ≥1）。

## 记忆节点与面板

- 记忆 = 画面中路旁的**发光光点**（小小的暖光晕，径向渐变，非贴图元素），每幕内沿路径走向排布在预设锚位（每幕 4~6 个锚位，按比例坐标写死在主题内，与画面透视一致）。
- 滚动至光点对应进度 ±半屏时光点亮起并浮现「年份 · 标题」小签；点击 / Enter 展开**纸面故事面板**（米白纸底 + 墨字 + 年份手记日期，`<dialog>`，Esc / 点外收起，开启时画面轻度模糊压暗）。
- 光点为 `<button>`，aria-label = 「年份 标题」，Tab 顺序 = 年份序；聚焦自动滚动到其进度。
- HUD：右下年份路标（随进度反解年份），EB Garamond oldstyle 数字。

## 动态层（Canvas 2D 粒子，无 WebGL 依赖）

- 单 `<canvas>` 叠加在画面之上，≤ 400 粒子，DPR ≤ 2：
  - 第一幕：蒲公英飞絮（暖白，缓慢横漂 + 上浮）
  - 第二幕：金色浮尘（细小，悬浮闪烁）
  - 第三幕：流星（间隔 3~6s 一颗，划向画面右下）+ 篝火火星（从篝火位置上升的橙色小粒）+ 星星微闪
- 幕间渐变带内粒子密度随透明度过渡，不硬切。
- 交叉渐变、粒子即全部动态——不做角色动画、不做视差。

## 文字与版式

- 中文：思源宋体 Noto Serif SC（400/600）；拉丁/年份：EB Garamond（含斜体）。
- 序章名字 display ≤ 4rem，叠在第一幕天空留白处，墨色 + 半透明纸色衬底保证 ≥ 4.5:1。
- 第三幕文字用米白纸色直接排在夜空，对比 ≥ 7:1；社交链接 = 篝火旁一列暖色小字链接（下划线浮现 hover 态）。
- 正文面板测量 ≤ 38em，行高 1.9。

## 色彩

- 页面基色随幕过渡：`--act1: oklch(0.92 0.05 75)` / `--act2: oklch(0.75 0.12 55)` / `--act3: oklch(0.22 0.05 265)`（用于页面底色、HUD、小签的协调，画面本身来自帧图）。
- 强调色 = 篝火暖橙 `oklch(0.75 0.14 55)`：光点、焦点环、链接。
- 纸面 `oklch(0.96 0.012 90)` + 墨字 `oklch(0.25 0.02 60)`（对比 ≈ 12:1）。

## 可访问性与降级

- 语义 HTML：三幕各为 `<section>` + 完整标题层级；画布与装饰 `aria-hidden`；「跳到当下」skip link。
- prefers-reduced-motion：关 Ken Burns 与全部粒子，幕间改简单透明度淡入淡出，光点静态显示，体验完整。
- 无 JS：`<noscript>` 列出三幕文字内容目录。
- 移动端（竖屏）：帧图 `background-size: cover` + 每幕焦点位（人物）`background-position` 锚定，保证人物始终在画面内；粒子减半。
- 键盘全可达，焦点环 = 暖橙双层光晕。

## 工程与素材

- 素材：3 张样张转 WebP（质量 82，单张目标 ≤ 500KB），存 `src/journey/assets/act-{1,2,3}.webp`；原 PNG 留 scratchpad 不入库。
- 文件：`journey.html`、`src/journey/main.ts`（装配+滚动）、`src/journey/acts.ts`（纯逻辑：进度→幕/透明度/年份映射，node 可自检）、`src/journey/particles.ts`（Canvas 2D）、`src/journey/style.css`。
- Vite 多页 input 恢复双入口；`tsconfig` 补 `vite/client` types。
- 纯逻辑自检：`node src/journey/acts.check.ts`（幕边界、渐变带透明度、年份映射单调性）。

## 禁令

- 禁分层拼贴视差、禁角色贴图/走路动画、禁写实厚涂、禁模板 portfolio 语法。
- 帧图之外不引入新画面元素（光点/文字/粒子除外）。
- 特效永不遮挡内容；文字对比度任何时刻达标。
