# 旧路 / The Long Road — 主题设计

芙莉莲（葬送的芙莉莲）动画风格的独立主题。体验宿命论，带淡淡的忧伤。

## 定位

- 与「深渊下潜」**并存可切换**的独立第二主题。
- **风格完全独立**：色板、字体、隐喻、代码均不参考深海站，只共享 `src/content/` 内容数据。
- 流程：本 spec 批准后**先出单文件视觉原型**（四时刻各一屏 + 花丛/面板样张，逐帧对照动画截图校色），原型认可后才进实现计划。

## 概念

**「旧路 / The Long Road」**——重走一生之路。

场景句：黎明时分从出生地出发，沿一条早已铺好的路穿过原野；蓝月草开花处藏着记忆，走到夜里，路在「当下」停住——流星落向还没走的远方。

宿命论的表达：**路早已在那里，你只是走到了这里**。忧伤不靠灰暗，靠辽阔和留白——天很大、人很小、时间不停。

## 信息架构

滚动 = 沿路前行（纵向滚动映射横向行进）。时刻由**路程进度**驱动，不由现实时钟驱动。

| 路程 | 时刻 | 内容 |
|---|---|---|
| 起点 0% | 晨曦 | 出生地：木路标刻名字 + 一句话 + 「沿路而行」提示（名片层） |
| 前段 | 上午→白昼 | 童年、成长的记忆花丛，按年份沿路分布 |
| 中段 | 白昼→黄昏 | 人生记忆带，走近花丛盛开、浮现故事 |
| 后段 | 黄昏 | 近年记忆，光线转金，旅人与树成剪影 |
| 终点 | 夜 | 当下：正在做的事 + 社交链接路牌 + 流星群落向前方未走的路，结语留白 |

- HUD：右下角**年份路标**（走到哪一年），把「路程=时间」挑明。
- 记忆节点 = **蓝月草花丛**，走近盛开、浮现文字。

## 色彩（动画对齐：低饱和、高明度、带灰的水彩调）

策略：**水彩平涂 + 纸感**。大面积柔渐变色块，无描边；全局叠细纸纹颗粒（约 3% 不透明度）。

```css
/* 时刻停靠点（天空/原野双渐变按路程进度插值） */
--dawn-sky:  oklch(0.90 0.04 60);   /* 晨：灰调桃金，近乎米色 */
--day-sky:   oklch(0.87 0.05 230);  /* 昼：带灰淡蓝，不是晴空蓝 */
--dusk-sky:  oklch(0.80 0.09 60);   /* 黄昏：柔金，饱和度收住 */
--night-sky: oklch(0.26 0.04 265);  /* 夜：蓝紫偏靛，不发黑 */

--meadow-day:  oklch(0.74 0.07 125); /* 草原：黄绿带灰，不是翠绿 */
--meadow-dusk: oklch(0.55 0.07 80);  /* 黄昏草色 */
--meadow-night:oklch(0.28 0.04 260); /* 夜草影 */

/* 主题色 */
--bluemoon: oklch(0.80 0.09 285);   /* 蓝月草淡蓝紫：记忆、焦点、交互 */
--paper:    oklch(0.96 0.012 90);   /* 阅读面板：米白纸面（全程恒定） */
--ink-on-paper: oklch(0.25 0.02 60);/* 纸上墨字，对比 ≈ 12:1 */
```

- **空气透视**：远景每退一层，颜色向当前天空色混 25~35%——远山几乎溶进天空；层间靠明度差分离，不靠描边。
- 色块**平涂 + 柔边**：边缘 1~2px 羽化，禁硬边矢量感。
- **阅读面板恒定纸色**：场景晨到夜怎么变，故事面板永远米白纸 + 墨字，可读性一劳永逸。
- 蓝月草淡蓝紫是唯一强调色：白昼是路旁一抹异色，夜里发光——同一颜色，时刻赋予不同意义。
- 夜段结语用 `--paper` 色直接排在夜空上，对比 ≥ 7:1。

## 构图（动画的画面语法）

1. **低地平线**：地平线固定在画面下 1/3，天空占 2/3，全程不破。
2. **云是主角**：白昼大朵扁底积云，黄昏染金压低，夜晚退场给星。
3. **人极小**：旅人剪影 ≤ 画面高度 8%，永远在下 1/3 区域内。
4. **稀疏**：同屏最多一处花丛、一个视觉焦点，留白即忧伤。
5. **逆光时刻**：黄昏段旅人与树全为剪影。

## 字体与版式

品牌声词：**辽阔、温柔、旧旅记**。

- **中文正文/标题**：思源宋体 Noto Serif SC（300/400/600）——绘本与旧书的文体。
- **拉丁/年份**：EB Garamond，oldstyle 数字——手记日期感；斜体用于引言/旁白。
- **竖排旁白**：宿命感短句 `writing-mode: vertical-rl` 立在留白处，像章节题词；只用于装饰短句，不可交互不进 Tab 序，正文永远横排。
- 流式标尺 clamp()，级差 1.25；display ≤ 4.5rem——辽阔靠留白不靠巨字。
- 正文测量 ≤ 38em（中文按字宽），行高 1.9；标题字距 +0.05em。

## 布局与交互

视口固定为舞台，`progress = scrollY / 总长`，五层视差平移：

| 层 | 内容 | 视差速率 |
|---|---|---|
| L0 天空 | 时刻渐变 + 云 | 0.05 |
| L1 远山 | 平涂剪影山脉 | 0.15 |
| L2 原野 | 草原色块 + 树 | 0.4 |
| L3 路面 | 道路 + 蓝月草花丛（交互层） | 1.0 |
| L4 近景 | 前景草叶掠过 | 1.6 |

- **旅人剪影**：披风旅人固定在画面左 1/3，景物后移产生行进感；终点停下，面向流星。
- **花丛交互**：花丛进入画面中央区域盛开 + 浮现年份和标题；点击/Enter 展开纸面故事面板（居中，38em，背景轻微模糊降饱和）；Esc/点击外部收起。
- **键盘**：Tab 在花丛间移动（自动行进到该花丛），Enter 展开，焦点为蓝月草色光环。
- **终点路牌**：社交链接 = 多向路牌，牌指向「远方的地名」（GitHub、邮箱等）。
- **移动端**：纵向滚动原义；层数减为 3（天空/原野/路面）；花丛与内容完整；近景草叶与部分粒子删除。

## 动效与粒子（混合：2D 底 + WebGL 粒子层）

**签名时刻两处**：

1. **启程**——首次滚动：路标文字随风散去，云影开始掠过草原，风粒子起。
2. **终点流星**——抵达夜段：星空亮起，流星群划向前方未走的路。情绪落点。

WebGL 只做一层全屏粒子（单 Points 系统 + 自定义 shader），形态随进度切换：

| 路段 | 粒子 |
|---|---|
| 晨 | 蒲公英种子、薄雾光尘（暖白） |
| 昼 | 花瓣、草絮，云影扫过原野（大暗斑缓移） |
| 黄昏 | 金色浮尘、归鸟剪影（远层稀疏） |
| 夜 | 星星渐显 + 流星拖尾 + 蓝月草辉光浮游 |

- **风向 = 行进反向**：滚动时粒子加速向后掠过；停下时回到慢漂——时间还在走。
- 滚动 lerp 0.08；花丛盛开 500ms ease-out-quart；面板 400ms 展开 / 300ms 收起；无弹跳缓动。
- 预算：粒子 ≤ 2000，DPR ≤ 2，移动端减半、关流星拖尾（保留星空）。

## 组件

- **年份路标 HUD**：右下角小路牌，EB Garamond oldstyle 数字显当前年份，路过花丛时短暂显示其标题。
- **纸面故事面板**：`--paper` 底 + 墨字 + 轻微纸纹，顶部年份手记日期式（「1998 · 夏」），无阴影堆砌。
- **花丛节点**：SVG 平涂蓝月草，2~3 种姿态随机取用；focus/hover = 盛开 + 淡蓝紫光环。
- **终点路牌**：多向指牌，hover 牌面微亮 + 地名下划线浮现。

## 可访问性与降级

- 语义 HTML：记忆带 `<section>` + 完整标题层级；特效层 `aria-hidden`。
- 对比度：纸面墨字 ≈ 12:1；场景上文字任意时刻 ≥ 4.5:1——晨昼浅底用墨色字（必要时衬半透明纸色底签），夜段深底用纸色字。
- 全站键盘可达 + 可见焦点。
- **prefers-reduced-motion**：无视差平移、无粒子漂移——静态分层构图 + 区段交叉淡入，花丛透明度渐显，流星改为定格星空长曝画面。体验完整不打折。
- **WebGL 不可用**：粒子层整体省略，2D 分层 + 内容完整可读，夜空用 CSS 星点。

## 工程边界

- 独立目录 `src/road/`（场景、样式、组件），**不 import 深海站任何模块**；只共享 `src/content/` 数据。
- Vite 多页入口：`index.html`（深海）+ `road.html`（旧路），互设一个不显眼的入口链接。

## 禁令

- 禁写实 3D、禁描边卡通线稿风（水彩平涂不是漫画）。
- 禁灰暗滤镜表达忧伤——忧伤靠辽阔、留白、时刻流转。
- 禁模板 portfolio 语法（技能条、头像卡、卡片网格）。
- 禁鲜艳饱和色——全色板贴动画的灰调水彩。
- 特效永不遮挡/延迟内容获取。
